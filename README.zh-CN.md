| [**Local_Image_with_Aina**](https://github.com/Yusameki/Local_Image_with_Aina) | 🆕 SDXL 参数基线、12GB 显卡上从零跑通 MOSS-Image 的部署记录，以及 LoRA 炼丹实录 — Project_Aina 的第一步 |
